# Student Registration System

A responsive Student Registration System built using HTML, CSS, and JavaScript DOM Manipulation.

---

## Features

- Add student records
- Edit student records
- Delete student records
- Form validation
- Data stored using localStorage
- Responsive design
- Dynamic vertical scrollbar

---

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Functionalities

### Add Student
Users can add student details including:
- Student Name
- Student ID
- Email ID
- Contact Number

### Edit Student
Users can edit existing student records.

### Delete Student
Users can delete student records.

### Local Storage
Student data remains saved even after refreshing the page.

### Validation
- Student name accepts only characters
- Student ID accepts only numbers
- Contact number requires at least 10 digits
- Email accepts valid email format
- Empty fields are not allowed
